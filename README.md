# 🚗 AutoTrack

**Sistema web para gerenciamento de veículos e controle de consumo de combustível.**

## 📌 Sobre o projeto

O AutoTrack é uma aplicação web desenvolvida com C# e ASP.NET Core MVC, com o objetivo de facilitar o gerenciamento de veículos e o acompanhamento de informações relacionadas ao consumo de combustível.

O projeto busca centralizar informações veiculares e possibilitar o registro e o acompanhamento de abastecimentos, quilometragem e gastos com combustível.

## 🎯 Objetivos

- Desenvolver uma aplicação web para gerenciamento de veículos.
- Organizar informações relacionadas aos veículos cadastrados.
- Estruturar o controle de consumo e gastos com combustível.
- Implementar a persistência de dados em um banco de dados.
- Aplicar conceitos de programação orientada a objetos, arquitetura MVC e desenvolvimento backend.

## 🛠️ Tecnologias utilizadas

- **C#** — linguagem de programação.
- **ASP.NET Core MVC** — desenvolvimento da aplicação web.
- **Razor Views** — construção das interfaces da aplicação.
- **Entity Framework Core** — integração com banco de dados.
- **Git e GitHub** — versionamento e gerenciamento do código-fonte.

## ✨ Funcionalidades previstas

- Cadastro e gerenciamento de veículos.
- Consulta e atualização de informações veiculares.
- Registro de abastecimentos e consumos.
- Associação de consumos aos respectivos veículos.
- Acompanhamento de gastos com combustível.
- Relatórios de consumo por veículo.

As funcionalidades serão implementadas progressivamente durante o desenvolvimento do projeto.

## 🏗️ Arquitetura

A aplicação utiliza o padrão arquitetural **Model-View-Controller (MVC)**, que separa as responsabilidades da aplicação em três componentes:

- **Models:** representação dos dados e das entidades.
- **Views:** apresentação das informações e interfaces do usuário.
- **Controllers:** processamento das requisições e coordenação das operações da aplicação.

Essa organização contribui para a separação de responsabilidades, a manutenção e a evolução do sistema.

## 📚 Objetivo de aprendizagem

O AutoTrack também é um projeto de estudo voltado à prática de desenvolvimento web com C# e ASP.NET Core MVC, explorando conceitos de orientação a objetos, operações CRUD, integração com banco de dados e versionamento de código.
